# Веб-приложение для финансовых аналитиков

## Проблема
Когда финансовые аналитики занимаются сбором и очисткой данных из разных источников(включая ЦБ РФ), они тратят 30% рабочего времени на эту рутину, потому что данные часто лежат в разных форматах (PDF, Excel), что ведет к потере времени, высокому риску ошибки человеческого фактора и снижению эффективности работы.

**источник [ЦБ РФ](https://www.cbr.ru/content/document/file/170699/recommendations_27122024_3.pdf)*


## Целевая аудитория

Возраст: 28–40 лет.

Пол: Без явного преобладания, примерно 60% мужчин / 40% женщин.

Образование: Высшее (экономическое, финансовое, математическое).

Уровень дохода: Выше среднего и высокий.

География: Вся Россия, но преимущественно финансовыми центрами являются Москва и Санкт-Петербург (около 50-60% аудитории).

Техническое понимание: 
Продвинутый уровень в Excel: формулы, макросы, сводные таблицы.
Хороший уровень в PowerPoint
Знакомы с SQL, 1с, Microsoft Power BI(или аналоги)
